# Lukas-comp — Workshop verze

Zamrznutá produkční verze pro workshopy. Data jsou pevná v kódu, needitovatelná přes UI.

Pro aktualizaci obsahu:

1. V pracovní verzi (aidetemcz/lukas-comp) uprav obsah přes editor (Ctrl+Shift+E)
2. Klikni Export, ulož si JSON
3. Pošli Claude Code prompt: "aktualizuj lukas-comp-workshop na tento stav" + přiložený JSON
4. Claude Code aktualizuje pouze default konstanty v tomto repu a pushne

Live: https://natalie908.github.io/lukas-comp-workshop/

DŮLEŽITÉ — nesahej na repo aidetemcz/lukas-comp. To zůstává beze změny, s editorem, s localStorage, jako pracovní verze.
